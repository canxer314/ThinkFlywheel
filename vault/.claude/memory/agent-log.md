## 示例条目（格式参考）

- **错误**: 在验证测试中，声称"工具 X 返回空"，实际是因为 limit 参数截断了结果
- **原因**: 先有结论再找证据——看到表面现象就直接当作验证依据，未复现就写入报告
- **教训**: 任何"工具失败"的断言必须先复现一次才能写入报告。limit 参数不能用于"是否存在"的判断。
