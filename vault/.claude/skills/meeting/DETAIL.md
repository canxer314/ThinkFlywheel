# /meeting 设计哲学与参考

> 此文件包含 SKILL.md 中移出的教育性内容和参考资料。
> Agent 不需要每次加载——仅在需要理解设计意图或查阅对比信息时读取。

## 核心理念

会议不是知识源，会议是**承诺、决议、摩擦的产生现场**。

处理会议的首要任务不是"提取知识"，而是回答四个问题：

1. **这场会议推进了哪些活跃任务/专案？**（更新）
2. **产生了哪些新的承诺与行动项？**（创建）
3. **做出了哪些决定？**（归档）
4. **暴露了哪些悬而未决的问题？**（追踪）

知识提取是**副产品**，不是主目的。

## 模式差异

| | fast | standard（默认） | deep |
|---|---|---|---|
| 结构化提取 | ✓ | ✓ | ✓ |
| 决议提取 | ✓ | ✓ | ✓ |
| 行动项提取 | ✓ | ✓ | ✓ |
| 知识提取（双提议） | ✗ | ✓ | ✓ |
| 风险/悬而未决追踪 | ✗ | ✓ | ✓ |
| 历史对照（Step 3） | ✗ | ✗ | ✓ |
| 适用场景 | 站会/快速同步 | 常规会议 | 关键客户会/复盘会 |

## 与 /ingest 的分工

| | /ingest | /meeting |
|---|---|---|
| 输入 | 文章、书籍、视频、播客 | 会议转录（有说话人标记） |
| 主目的 | 知识提取 | 承诺/决议/行动提取 |
| 产出 | reading 摘要 + atomic 卡片 | 会议纪要 + task + decision |
| 任务关联 | 标注 related_tasks | 主动创建/更新 task |
| 历史对照 | 无 | 有（prev_meeting 链） |

## 技能关系图

```
Sources/inbox/ (会议转录)
    │
    ▼
/meeting
    │
    ├─→ /decide 通道 → Decisions/ (决策记录)
    ├─→ /task 通道   → Tasks/active/ (新建/更新任务)
    ├─→ /note 通道   → Cards/ (知识卡片，双提议)
    └─→ Project 更新  → Projects/active/ (风险/问题追加)
    │
    ▼
Cards/reading/ (会议纪要, subtype: meeting)
    │
    ▼
下一次 /meeting → Step 3 历史对照 → 飞轮加速
```

`/meeting` 不替代 `/ingest`——非会议类材料（文章、书籍、视频）仍走 `/ingest`。
