# /note 设计哲学与参考

> 此文件包含 SKILL.md 中移出的教育性内容和参考资料。
> Agent 不需要每次加载——仅在需要理解设计意图或查阅上下游关系时读取。

## 核心理念：地图 + 石头

每次 `/note` 产出两层内容：

1. **研究摘要（地图）** — 一张完整的叙事性卡片，保留讨论的脉络、推理链条和结论。读这张就能还原整个研究过程。
2. **原子卡片（石头）** — 从摘要中提炼的独立知识点，每张可脱离上下文复用，最终进入 FSRS-6 间隔重复。

**地图让石头有意义，石头让地图可链接。**

## 定位

`/note` 是 vault 中知识类卡片的**唯一写入通道**（SCHEMA.md §3）。

| 上游 | 下游 |
|------|------|
| `/ingest` 处理来源后的结构化内容 | `/review` 原子卡片进入 FSRS-6 复习 |
| `/retro` 任务复盘后的教训提取 | `/query` 卡片被检索时找到 |
| 纯对话中产生的洞察和认知 | `/briefing` 复习卡片交叉引用到活跃任务 |

## 与 /retro 的关系

`/note` 和 `/retro` 都会触发知识提取，但入口不同：

| | /note | /retro |
|--|-------|--------|
| 触发场景 | 对话中产生了知识 | 任务完成后做复盘 |
| 主要来源 | 讨论、阅读、分析 | "问题与吐槽"中的实际经验 |
| 卡片类型偏好 | concept、atomic | insight、atomic |
| 是否归档任务 | 否 | 是 |
